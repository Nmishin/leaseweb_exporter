# Security Policy

## Supported Versions

Only the latest release receives security fixes.

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub:

1. Open the [Security tab](https://github.com/Nmishin/leaseweb_exporter/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, affected versions, and steps to reproduce.

Direct link: <https://github.com/Nmishin/leaseweb_exporter/security/advisories/new>

You will get a response as soon as possible. Once a fix is released, the advisory will be published.
